Design invariants:
- game_trophies is authoritative; missing/deleted screenshots never unearn trophies.
- PS5 local state is /data/savestate-sync/trophy-sync.state.
- Only HTTP 200 marks local discovery fingerprints processed.
- HTTP 409 means only SYNC_LOCKED; it remains pending.
- HTTP 207/5xx/network failure leaves local discoveries pending.
- Duplicate submissions are safe via idempotent database writes.
- Backend lock expires after 10 minutes.
- Last attempt and last successful sync are stored separately.
